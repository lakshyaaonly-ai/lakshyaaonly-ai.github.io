# Lakshya Rajpal — Developer Portfolio

A responsive, dark-themed personal portfolio built with plain HTML, CSS and JavaScript.

## Before publishing

1. Open `index.html` and replace:
   - `+91-XXXXXXXXXX` with your phone number.
   - `your.email@gmail.com` with your professional email.
   - `[LinkedIn Profile URL]` with your LinkedIn URL, or remove the LinkedIn item if you do not want to include it.
2. Open `script.js` and update:
   - `email` with the same professional email.
   - `linkedinUrl` with your full LinkedIn profile URL, or leave it blank.
3. Check every skill and project statement. Keep only skills you can explain and project claims that match your actual code.
4. Add a PDF resume if you want a working “Download CV” link. The current site intentionally does not include a fake download button.

## Run locally

Open `index.html` in a browser. No build tools or package installation are required.

## Publish with GitHub Pages

1. Create a GitHub repository named `lakshyaaonly-ai.github.io` (if available for your account).
2. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Your URL will be `https://lakshyaaonly-ai.github.io/`.

If you use a repository with another name, the URL will usually be `https://lakshyaaonly-ai.github.io/REPOSITORY-NAME/`.

## Notes

- The page uses Google Fonts when an internet connection is available; system fallbacks are defined.
- No backend, analytics, tracking scripts or external JavaScript libraries are used.
- The GitHub project link is based on the repository URL supplied for the project.
